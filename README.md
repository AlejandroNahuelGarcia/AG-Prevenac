# AG PREVENAC — Prototipo web

Prototipo inicial de rediseño corporativo desarrollado con HTML, CSS y JavaScript.

## Cómo verlo
1. Descomprimí la carpeta.
2. Abrí `index.html` en tu navegador.
3. Para trabajar cómodamente, podés abrir la carpeta con Visual Studio Code y usar Live Server.

## Estructura
- `index.html`: contenido y estructura.
- `css/styles.css`: estilos, paleta y responsive.
- `js/main.js`: menú móvil, año automático y validación visual del formulario.

## Antes de publicar
- Reemplazar el logo tipográfico provisional por el logo oficial.
- Confirmar y actualizar correo, teléfono y WhatsApp.
- Revisar y aprobar los textos y servicios con AG PREVENAC.
- Reemplazar las fotografías de muestra por imágenes autorizadas de la empresa o imágenes con licencia adecuada.
- Conectar el formulario a un backend o servicio de formularios. Actualmente es solo demostrativo y no envía mensajes.
- Configurar dominio, hosting, HTTPS, SEO y analítica según corresponda.

Las imágenes remotas y los íconos requieren conexión a internet.
